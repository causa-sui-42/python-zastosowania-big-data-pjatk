# 📚 Polecane Książki

Poniżej lista książek, które prowadzący poleca — od podwalin Big Data po zaawansowany PySpark.

## Obowiązkowe (dostępne online przez uczelnianą bibliotekę)

| Tytuł | Autorzy | Poziom | Uwagi |
|-------|---------|--------|-------|
| *Learning Spark, 2nd Edition* | Damji, Wenig, Das, Lee | ⭐⭐ Średni | Najlepsza książka o Spark + PySpark; darmowa na [O'Reilly](https://learning.oreilly.com) |
| *Hadoop: The Definitive Guide, 4th Ed.* | Tom White | ⭐ Podstawowy | Biblia Hadoop — HDFS, MapReduce, YARN od podstaw |
| *Programming Python for Data Science* | Mark Fenner | ⭐ Podstawowy | Świetne wprowadzenie, jeśli potrzebujesz odświeżyć Python |

## Polecane (nie wymagane)

| Tytuł | Autorzy | Poziom | Uwagi |
|-------|---------|--------|-------|
| *Spark: The Definitive Guide* | Chambers & Zaharia | ⭐⭐⭐ Zaawansowany | Głęboka wiedza o wewnętrznościach Sparka |
| *Designing Data-Intensive Applications* | Martin Kleppmann | ⭐⭐⭐ Zaawansowany | Klasyk architektury systemów danych — must-read na wyższy poziom |
| *Kafka: The Definitive Guide, 2nd Ed.* | Shapira, Palino et al. | ⭐⭐ Średni | Wszystko o Apache Kafka |
| *Python for Data Analysis, 3rd Ed.* | Wes McKinney | ⭐ Podstawowy | Autor pandas wyjaśnia pandas — bardzo praktyczna |
