Laboratorium 6: BigQuery, Dataproc i Spark w chmurze GCP

Czas trwania: ~90 minut  |  Poziom: Średni  |  Semestr: Letni 2025/2026

🎯 Cel ćwiczenia​

Twoja firma DataDrive Polska 🛒 otrzymała zlecenie — analiza danych sprzedażowych z BigQuery public datasets. Nauczysz się korzystać z chmury Google do analizy Big Data.

Laboratorium składa się z dwóch części:

  • Część A (ćw. 1-4): BigQuery — zapytania SQL na publicznych zbiorach danych (free tier)
  • Część B (ćw. 5-7): Dataproc — tworzenie klastrów Spark i submittowanie jobów (walkthrough)

Google Cloud Skills Boost — ćwicz bez karty kredytowej!

Wszystkie komendy z tego laboratorium możesz przetestować w prawdziwej chmurze GCP bez karty kredytowej dzięki Cloud Skills Boost!

🟢 Darmowe laby — zacznij od tych:

  • Dataproc: Qwik Start - Command Line — gcloud dataproc 1:1 z tym ćwiczeniem
  • Dataproc: Qwik Start - Console — klaster przez GUI
  • BigQuery: Qwik Start - Console — SQL na publicznych danych
  • Cloud Storage: Qwik Start - Console — bucket i upload plików

🔵 Zaawansowane laby:

  • Running Apache Spark jobs on Cloud Dataproc — pełny flow Spark na Dataproc
  • Perform Foundational Data, ML, and AI Tasks — quest (6h)
  • Data Engineering on Google Cloud — ścieżka (16h)

🖥️ Google Cloud Shell — shell.cloud.google.com — darmowy terminal gcloud dla każdego użytkownika Google (wystarczy Gmail, bez billing account).
